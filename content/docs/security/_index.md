Security added at the end is a compliance exercise. Security designed in is an
architectural constraint that shapes boundaries, data flow, and blast radius —
and it costs far less when it arrives early.

This section covers threat modelling you can finish in an hour, where identity
and authorisation boundaries belong, secret handling that survives an audit,
software supply chain integrity, and designing for least privilege and
auditability from the start.
